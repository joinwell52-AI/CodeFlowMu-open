# CodeFlowMu Open — Historical Open Edition

> **FROZEN / HISTORICAL** — This repository was frozen on **2026-08-22**.

`CodeFlowMu-open` is the historical open-source edition of CodeFlowMu. It is preserved for engineering history, research reference, reproducibility, and users who still depend on the last open release.

## Status

- Last open edition: **V1.2.29-open**
- No new feature development
- No synchronization from the current private CodeFlowMu development repository
- No new Open Edition releases are planned from this repository
- New feature pull requests are not requested
- This repository is **not** the source of current CodeFlowMu customer releases

The CodeFlowMu project itself has not stopped. Current CodeFlowMu development continues as a separate **closed-source product line**, and its source repository is no longer public.

## Historical scope

CodeFlowMu Open provided a local-first multi-agent development team with PM / DEV / OPS / QA roles, independent EVAL observation, FCoP task/report/evidence workflows, PC Panel, Mobile PWA, Cursor SDK integration, and controlled Windows/Browser Use.

This edition predates the formalization of TMPA V1.0 and is part of the engineering history that informed later CodeFlowMu and TMPA work. It is not claimed as the current CodeFlowMu implementation or as a current TMPA-conformant reference implementation.
