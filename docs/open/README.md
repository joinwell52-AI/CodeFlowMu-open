# CodeFlowMu Open Dev Team Edition

这是公开开源版的版本首页内容源。

本目录由母体仓库维护，并在执行 `npm run build:open-dev-team` 时生成到公开仓库的 `docs/open/`。

- [PC 帮助手册（含版本化截图）](help.md)
- [快速开始](getting-started.md)
- [版本边界](edition-boundary.md)

公开版定位：

- 固定开发团队：PM / DEV / OPS / QA；EVAL 独立观察
- 面向开源下载、安装、体验、二次开发和贡献
- 默认本地运行，不连接私有网关
- 保留 Git 状态、项目配置、任务/报告/审批/聊天等基础协作能力
- 不携带母体运行记录、私有日志、真实项目数据、私有网关凭据和内部实验功能
