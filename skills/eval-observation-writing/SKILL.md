# EVAL Observation Writing

## When to use

Use when recording observed behavior or gaps.

## Rules

- State what was seen.
- Attach evidence.
- Describe impact and confidence.
- Suggest follow-up without changing lifecycle.

## Required output

Use `docs/skills/eval-playbook/observation-writing.md`.

## Forbidden actions

- Do not treat observation as REPORT.
- Do not change lifecycle.
- Do not overclaim without evidence.

## Minimal example

```text
Observation: README lacks Chinese version
Impact: ADMIN discovery friction
Follow-up: local DEV task
```
