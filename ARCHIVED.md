# CodeFlowMu Open — Historical Open Edition

> Repository freeze date: 2026-08-22

`CodeFlowMu-open` is now frozen as the historical open-source edition of CodeFlowMu.

## Frozen status

- Last open edition: `V1.2.29-open`
- No new feature development
- No synchronization from the current private CodeFlowMu development repository
- No new Open Edition releases are planned from this repository
- No new pull requests or feature contributions are requested
- Existing source history and historical releases remain available for research, reference, and users who still depend on this edition

The current CodeFlowMu product line is developed separately in a private development repository and is distributed through a separate product-distribution process. This historical repository is not the source of current CodeFlowMu customer releases.

For current public research, architecture, and project-family information, see:

- TMPA / Digital Employee Works: https://joinwell52-ai.github.io/joinwell52/
- FCoP: https://github.com/joinwell52-AI/FCoP

## License boundary

Freezing this repository does not retroactively change the license of code that was already released here. Historical CodeFlowMu Open source remains governed by the license terms under which those versions were published.

Future private CodeFlowMu product code is not published through this repository.

## Why the repository remains available

The repository is preserved because it is part of the engineering history of CodeFlowMu and TMPA, and because previously published links, releases, documentation, and user references should remain reproducible.

It should be treated as a historical snapshot, not as the current product implementation.
